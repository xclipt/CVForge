# CVForge

AI-assisted ATS resume builder for Visual Studio Code.

## Vision

CVForge is an open-source toolkit that combines LaTeX, AI assistance, and VS Code into a professional resume authoring environment.

Instead of editing one large resume file, users maintain structured resume data and generate polished ATS-friendly resumes from reusable templates.

## Features

- ATS-friendly LaTeX templates
- AI-assisted writing
- Modular resume data
- VS Code integration
- Automated builds
- Multiple resume variants
